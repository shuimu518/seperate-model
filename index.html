任务要求 goal

请调研上海（Shanghai）2026年10月18日（明天）的天气情况。

【调研内容】
1. 全天天气概况：晴/多云/阴/雨，天气现象
2. 气温：最高温、最低温（℃）
3. 降水：降水量（mm）、降水概率（%）
4. 风力风向：风力等级、风向
5. 空气质量：AQI指数、首要污染物、空气质量等级
6. 逐时段变化：早（6-9点）、午（11-14点）、晚（18-21点）三个时段的气温与天气
7. 出行提示：穿衣建议、是否需要带伞、紫外线强度

【数据源要求】
- 中国气象局（cma.gov.cn）/ 中央气象台
- 上海市气象局官网
- 和风天气 / 墨迹天气 / 彩云天气等主流天气服务
- 至少2个独立来源交叉验证

【输出要求】
直接在对话中输出 Markdown 格式文本，采用表格呈现：
- 表1：上海 2026-10-18 天气总览（天气现象/温度/降水/风力/AQI）
- 表2：逐时段预报（早/午/晚）
- 表3：多源数据对比（各家预报是否一致）
- 出行建议：2-3条

【可信度标注规则】
✅ 有权威源（气象局/官方）
⚠️ 多源不一致（列出各家数字）
❓ 查不到（写❓，不许编造数字）

【重要】
- 必须明确是 2026年10月18日当天，不是今天
- 查不到的数据标❓，绝不许编造
- 温度必须带单位℃
