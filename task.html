任务要求 goal

查询台州（浙江省台州市，椒江区）未来一周（7天）天气预报。

【必须包含】
1. 逐日预报表格：日期 / 星期 / 天气现象 / 最高温 / 最低温 / 风力风向 / 降水概率
2. 数据来源标注：每个数据点标注来源，查不到标❓，不许编造
3. 出行提示：根据天气给出穿衣、出行、是否带伞的实用建议
4. 一周趋势总结：温度走势、是否有明显降温/降雨过程

【城市定位】
台州，浙江省，坐标约 28.66°N, 121.42°E

【输出格式】
直接在对话中输出 Markdown 格式文本（不要生成文件），用表格呈现逐日数据，末尾附来源 URL 列表。

【数据源建议】
- 中国天气网 weather.com.cn
- 中央气象台 nmc.cn
- 浙江省气象台
- 或权威第三方天气 API

【质量要求】
- 温度数据必须来自权威来源，不要用记忆里的数据
- 不同来源数据有冲突时标注出来
- 查不到的字段标❓，绝对不许编造
